步驟

  1. 用 USB 傳輸線接上電腦
  2. 按「安裝」，選擇序列埠後連線
  3. 按 Install GT7 Dash
  4. Erase device 不要勾，按 Next
  5. 按 Install，等約一分鐘
  6. 完成。沒有自動重開就按 RESET

常見問題

勾了 Erase device 會怎樣？

所有設定都會清除，包含 Wi-Fi、機器名稱和設定熱點的密碼。

找不到序列埠

選 USB JTAG/serial 或 CH343。沒有的話換線、換 USB 孔，或安裝 CH343 驅動程式。

連不上

按住 BOOT，按一下 RESET，放開 BOOT，再按「安裝」。燒完後按 RESET。

測試版是什麼？

試用中的新功能。隨時可以重裝穩定版，設定會保留。
