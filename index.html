GT7 Dash 線上燒錄

用 USB 線把儀表接上電腦，直接在這個網頁安裝或更新韌體，不需要安裝 Arduino IDE。原本的 Wi-Fi 和各項設定都會保留。

這個瀏覽器不支援 USB 燒錄。請改用電腦版的 Chrome、Edge 或 Opera。Safari、Firefox 和手機都不能使用。

安裝步驟

  1. 用可以傳資料的 USB 線把儀表接上電腦（只能充電的線不行）。
  2. 按上面的「安裝」，瀏覽器會列出序列埠。選 USB JTAG/serial debug unit 或 USB-Enhanced-SERIAL CH343 開頭的那一個，再按「連線」。
  3. 出現英文視窗後按 Install GT7 Dash。
  4. 接著會問 Erase device。不要勾選，直接按 Next，設定就會保留。
  5. 按 Install 開始燒錄，大約一分鐘。過程中不要拔線。
  6. 看到 Installation complete! 就完成了。如果儀表沒有自己重新開機，按一下板子上的 RESET。

之後的更新可以直接在儀表選單的韌體頁面檢查更新，不一定要再接電腦。

常見問題

勾選 Erase device 會怎樣？

整片記憶體會先清空，等於恢復成全新的狀態：

  • Wi-Fi 設定、目標主機、儀表樣式等所有設定都會消失，開機後要重新用手機設定 Wi-Fi。
  • Wi-Fi 設定熱點的密碼會重新產生，之前拍下或印出來的 QR 碼就不能用了。
  • 自訂的機器名稱也會清掉。

只有在儀表怪怪的、重灌也沒用時才需要勾。

列表裡找不到序列埠
  • 換一條 USB 線，或換到板子上的另一個 USB 孔。
  • 如果板子是接 CH343 那個孔，Windows 可能要先安裝 WCH 的 CH343 驅動程式。
  • 關掉 Arduino IDE 的序列埠監控視窗或其他正在用這個序列埠的程式。
一直停在連線中，或出現 Failed to initialize

手動讓板子進入燒錄模式：按住 BOOT 不放，按一下 RESET，再放開 BOOT。然後重新按「安裝」。燒完後要再按一次 RESET 才會開機。

穩定版和測試版有什麼不同？

測試版是還在試用的新功能，可能有問題。裝了測試版之後，儀表會從測試版頻道檢查更新；等下一個穩定版推出，就會自動回到穩定版。這裡只在測試版比穩定版新的時候才會出現測試版。

從測試版改回穩定版

直接在這裡按「安裝穩定版」即可，設定會保留。

燒錄工具使用 ESP Web Tools。韌體版本記錄請看 GitHub Releases。
